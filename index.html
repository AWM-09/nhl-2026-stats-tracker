Tracker notes

DATA STATUS
The tracker retrieves schedules and game boxscores from the NHL public web API. It may take a little time to load games.
Goals, assists, points, shots, hits, blocked shots and goalie statistics are sourced from game-level boxscores. Faceoff and goalie percentages are averaged across the selected game rows; they are not added together.
Data source: NHL public web API. API endpoints are community-documented and may change. This is an independent fan-made tracker, not affiliated with the NHL.
